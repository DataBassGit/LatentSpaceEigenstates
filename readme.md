## **Usage**

**Requirements:** torch, transformers, pandas, matplotlib, seaborn

**1\. Harvest the Data:**

Configure the CONFIG dictionary in labeled\_pipeline.py to target your specific model and target layer, then run:

python labeled\_pipeline.py

The script will automatically forge the contrastive anchor, decompose the Gram matrix, execute the harvest, and populate the extracted\_vectors/ directory.

**2\. Visualize the Physics:**

Once the harvest is complete, run the visualization scripts to graph the energy distributions of the generated semantic attractors.

To plot the absolute amplification within the deepest introspective trench:

python visualize\_evaluations.py

To plot the general structural gravity (Rayleigh Quotient) across all semantic states:

python visualize\_rayleigh.py

Both scripts will automatically scan the extracted\_vectors/ directory and output high-resolution .png graphs to your root folder.
